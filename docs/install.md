# Installing Pager

(Adapt for july.dev/bff-pager.)

1. **Download** Pager.zip and unzip it. Drag **Pager.app** to Applications.
2. **Open it.** macOS will block it ("Apple could not verify…") because this
   build isn't notarized yet. Close the dialog — don't move it to Trash.
3. Open **System Settings → Privacy & Security**, scroll down, and click
   **Open Anyway** next to "Pager.app was blocked…", then confirm **Open**.

That's it — Pager lives in your menu bar (📟). On first run it asks you to
create a pager (send the code to your BFF) or join with a code you received.
Enable "Launch at login" so it's always there.
